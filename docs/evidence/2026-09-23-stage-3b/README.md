## OKR 弹窗（D2）

在独立临时 SQLite 数据库的本地后台，以真实 Edge 页面创建并编辑测试周期。桌面 1280 × 800 下，新建弹窗约为 x=280、y=132、宽 720、高 536，四周空间相称；编辑弹窗同样居中。375 × 812 下，新建和编辑弹窗均为 x=12、宽约 351、y≈29、高约 753。okr-new-desktop.png、okr-edit-desktop.png、okr-new-mobile-375.png、okr-edit-mobile-375.png 是对应截图。

短屏幕 375 × 600 首次发现弹窗贴住上下边界；okr-short-mobile-before.png 记录问题。修复后上下各留 16 像素、弹窗高 568 像素，内部内容高 752 像素且可滚动，见 okr-short-mobile-after.png。还复现并修复遮罩上滚轮会滚动背景的问题：弹窗打开时页面滚动被锁定，表单内滚轮仍滚动表单；关闭后原页面滚动设置恢复。新建状态验证了 Escape、关闭按钮、取消按钮均关闭并把焦点交还“新建周期”；点击遮罩不关闭，焦点仍在弹窗内，符合现有约定。编辑状态验证 Escape 后焦点返回对应编辑按钮。上述交互使用实际浏览器操作，不以源码断言替代。

## 前台入口、转换与展示说明（D3、D4、E2、E3）

- 375 CSS 像素首页无横向溢出，知识库与在线简历入口均能访问；无公开 PDF 时 /resume 仍可打开，不出现下载链接。
- 周报草稿 A 有未保存输入时，取消转换草稿 B 的确认不会发出转换请求，确认后 B 转换为私有职业动态并直接打开对应编辑页；返回周报重新编辑 A 时出现恢复提示，未保存标题仍在。
- 里程碑和时间线草稿分别验证：编辑 A 时转换 B 被阻止、没有请求且输入保留；取消编辑后转换 B，均直接打开对应新动态的编辑页。converted-activity-target.png 展示周报转换目标的编辑态。
- 三类草稿分别模拟“HTTP 200 但状态仍为 DRAFT、无目标 ID”的转换响应：页面不跳转，原草稿仍在，出现“转换响应缺少可打开的动态”提示；周报的当前编辑器仍保留。
- 在同一个未重载的职业动态页面，用应用路由从周报目标 A 切到时间线目标 B，编辑器标题随目标 ID 改变，页面内测试标记仍在。
- public-readiness-blocked-ready.png 同屏展示私密 OKR 周期的阻断原因和公开双语周期的“满足前台展示条件”；两者均保留展示去向与生效步骤。

上述草稿和周期均为临时本地验收数据，不代表生产内容。截图与结果只证明本地代码和临时库，不证明合并、部署或线上验收；真实中文输入法输入仍留在 F2。
