# 阶段 3C 本地验收记录

## 已有证据

- 项目卡片偏差、不可用源项目、旧版快照、显式空选择、非项目图片路径保留与服务端过期保存拒绝均有自动化测试。最终聚焦回归 5 个文件／150 项、全量回归 77 个文件／531 项通过。
- TypeScript、ESLint、设置本地临时数据库连接串后的 Prisma schema 校验和 Git 变更检查通过。
- 全新临时 SQLite 数据库应用 32 个迁移、完成 seed；另一全新临时 SQLite 数据库应用 32 个迁移、完成 seed 和生产构建。构建只证明本地代码可构建，不证明部署。
- 独立代码审查未发现 Stage 3C 的 Critical／Important 问题。
- 验收时发现初始化表单缺少原生 POST：脚本尚未接管的提交可能使密码进入地址栏。已增加失败后通过的回归测试、补上 POST 提交方式，确认本地实际 HTML 含 POST 表单，并清理验收窗口的当前地址。曾输入的密码不再用于后续本地验收；如在别处复用，应更换。

## 浏览器矩阵

在本机 3018 的独立临时 SQLite 库和生产构建中，使用两项合成公开项目与用户自行初始化的管理员会话完成验收。测试图像上传到本阶段独立的临时媒体目录。此处不记录密码、Cookie、Token 或原始网络追踪。

| 检查项 | 真实浏览器结果 |
| --- | --- |
| 源项目更新后仅明确检查才报告差异 | 中文标题、英文描述、技术标签顺序在第二后台标签页改变后，内嵌预览与公开页仍是旧卡片；点击检查后才列出相应字段。 |
| 检查失败与恢复 | 在页面内阻断一次项目 GET，出现错误提示、同步按钮禁用，未保存介绍及链接保留；再次检查成功后恢复。 |
| 同步仅改变工作副本 | 紧邻同步提交的 iframe 中文介绍与未保存 GitHub 链接均保留，内嵌项目卡片更新、工作副本变脏；同步没有草稿 PUT 或发布 POST。 |
| 图片替换保留 | 在可视化预览里选择人物图、从隔离媒体库替换图片，再检查并同步源项目；新图仍显示在工作副本，已保存草稿仍保留原图，测试图片返回 HTTP 200。 |
| 保存和发布分层 | 同步后独立草稿预览与公开页仍旧；明确保存后草稿与独立预览更新、公开页仍旧；明确发布后公开页更新。 |
| 项目不可用与过期保存 | 两个项目同时变化可列出差异；其中一项改为私密时显示原因和项目管理入口、同步禁用，恢复公开后可再检查。同步后源项目再变化，保存返回 400 并保留未保存内容；重新检查、同步后保存成功。 |
| 旧版、显式空选择、小屏 | 旧版卡片只显示迁移说明；测试夹具中的显式空选择加残留卡片提示待清理，同步后仅工作副本变脏。375 CSS 像素下页面滚动宽度也是 375，同步面板和手机预览均可用。 |

脱敏请求顺序只记录方法、路径与状态：检查为 GET /api/admin/projects 200；模拟失败为同一路径 blocked，重试为 200；检查／同步期间没有主页写请求；过期保存为 PUT /api/admin/site/draft 400；再次检查和同步后同一路径 PUT 200；明确发布才有 POST /api/admin/site/publish 200。保存和发布成功后另有读取草稿、版本的 GET。
