# 尚需人工或环境信息的验收

## 真实系统中文输入法（F2）

必须在隔离本地库中实际使用Windows中文输入法，模拟composition事件或直接填中文字符串不能通过此门槛。当前证据只有模拟组合事件及真实浏览器行为，没有系统IME操作。

1. 打开已认证首页CMS可视化预览，用系统拼音输入法编辑中文首屏标题，实际选词完成；确认文字、光标和未保存修改保留。
2. 保持原位焦点直接刷新/关闭，选择取消后确认输入仍在；已完成选词后保存，刷新回读必须为保存值。
3. 在组合输入尚未结束时点击保存，确认flush等候选词结束，最终完整文字只保存一次，没有中间拼音或旧值。
4. 实际编辑中文后切字段视图、语言或设备预览，再返回；核对未保存工作副本和当前选择没有丢失。

只记录本地验收结果，不在生产草稿上完成该检查。获得实际人工操作结果后才可勾F2。
